Файл .nojekyll рядом обязателен для GitHub Pages.
Без него Pages пропускает страницу через Jekyll, а тот игнорирует папки,
имя которых начинается с подчёркивания. Next кладёт всю сборку в _next,
поэтому без .nojekyll сайт отдаёт голый html без стилей и скриптов.
Лежит в public/, потому что оттуда Next копирует его в out/ на каждой сборке.
